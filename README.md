# Scratches

Ferramenta local para DJs pesquisarem músicas, explorarem letras e organizarem trechos em projetos para suas linhas de scratch.

O projeto está em desenvolvimento. As integrações com APIs e a primeira versão para distribuição ainda serão concluídas e revisadas. Não há uma versão instalável publicada neste momento.

## Publicação

Este repositório começa com a apresentação do projeto. O código destinado à distribuição será publicado após revisão. A criação do repositório não publica automaticamente os experimentos mantidos localmente.

Só entram no histórico público arquivos necessários para manter e distribuir a aplicação. Pesquisa, planejamento interno, referências visuais, capturas de tela, caches, dependências instaladas, credenciais, catálogos pessoais, letras, projetos e backups ficam fora dele.

As atualizações serão distribuídas por Releases estáveis, com notas de versão e pacote verificado por SHA-256. Um commit na branch principal não anuncia uma atualização aos usuários. Cada Release exige revisão dos arquivos, testes e conferência do pacote.

## Dados locais

O Scratches mantém projetos e letras no computador de quem usa a aplicação. Esses dados não são enviados para este repositório e não fazem parte dos pacotes de atualização.
